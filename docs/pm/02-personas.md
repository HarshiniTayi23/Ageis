## Starting points

1. **Backup / IT admin**: on call during an incident; has to restore.
2. **CISO / security leader**: decides pay vs restore; answers to the board.
3. **AI platform owner**: has given AI agents write access to production data; is responsible when one misbehaves.

**Questions to think about while writing:**
- Which persona is *primary* for Milestone 1? For Milestone 2?
- Where do their needs conflict? (Hint: the admin wants agents to never be blocked; the CISO wants every destructive action reviewed.)
